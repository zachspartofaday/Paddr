# Contributing to PuckPads

Bug reports and focused pull requests are welcome. This project targets newly released beta controller support, so please include your macOS build, connection mode, controller identifiers with serial numbers removed, and clear reproduction steps.

Before opening a pull request:

- keep changes narrowly scoped;
- do not commit raw hardware captures, serial numbers, private IOHID paths, credentials, or generated build products;
- run `swift test` with the Xcode-beta toolchain; and
- explain any controller or permission behavior you could not test directly.

`@zachspartofaday` is the project owner and code owner. Community discussion and review comments are welcome, but only the owner's approval is binding and only the owner merges changes.

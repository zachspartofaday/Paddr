# README screenshots

Captured from the running local Paddr app on macOS 27 Developer Beta 8, build `26A5425a`,
on 2026-09-07. The app includes the window and rear-button help changes merged in
[#89](https://github.com/zachspartofaday/Paddr/pull/89) (`adcff16`).
The captures show real app windows, not mockups.

- `paddr-profile-overview.png`: saved World of Warcraft profile, left Scroll/right Pointer,
  current pointer controls, and the Rear buttons card.
- `paddr-zones-*.png`: all five left-trackpad zone layouts, with right Pointer.
  These are unsaved example drafts, not shipped presets.
- `paddr-onboarding.png`: guide welcome page.
- `paddr-permissions.png`: guide page 3, with both permission requests.

The local ad-hoc build had neither permission granted, no puck connected, and mapped output off.
These UI captures do not themselves establish hardware compatibility; the Beta 8 compatibility
note records the maintainer's confirmation of their current setup.
